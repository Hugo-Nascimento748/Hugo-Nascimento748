## 📂 Projetos em Destaque

### 💈 Barber Flow
Sistema **SaaS de gestão financeira para barbearias**, construído como PWA mobile-first e usado por clientes reais.

- Arquitetura **multi-tenant** com Supabase RLS (Row Level Security), garantindo isolamento total de dados entre usuários
- Dashboard analítico interativo (Recharts) com métricas financeiras, ticket médio e ranking de performance
- Sistema de PDV com taxas dinâmicas de operadoras de cartão, controle de estoque e gestão de recebíveis
- Interface em TailwindCSS + Framer Motion seguindo padrões de design mobile-first

**Tecnologias:** React · TypeScript · TailwindCSS · Supabase (PostgreSQL, RLS) · Framer Motion
